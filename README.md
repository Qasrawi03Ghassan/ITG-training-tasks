# **Simple REST photos uploader and downloader - Learning Spring**  
 This project features a simple REST photo uploader app using Spring with H2 DB implemented during learning Spring & Spring Boot.  
 ### features  
 - Uploading photos using a simple HTML page.
 - Searching and downloading photos present in the database based on thier IDs through HTTP get methods (**/api/photos/{id}** for search, and **/download/{id}** for download).
 - Deleting a specific photo via an HTTP delete method depending on it's ID.
 - Accessing all photos' metadata through the HTTP get method **/api/photos**.
